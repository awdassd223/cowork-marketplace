# Lesson Writer

주제 하나를 받아 **비개발자도 따라올 수 있는 강의안 한 편**을 작성하는 스킬이다.

## 입력값

| 항목 | 필수 | 기본값 |
|------|------|--------|
| 주제 | 필수 | — |
| 대상 학습자 | 선택 | 비개발자 실무자 |
| 강의 길이 | 선택 | 50분 |

주제가 주어지지 않으면 먼저 사용자에게 "어떤 주제로 강의안을 만들까요?"라고 묻는다.

## 작성 절차

1. **입력 확인** — 주제·대상·길이를 확정한다. 빠진 값은 기본값을 쓰거나 한 번만 되묻는다.
2. **구조 작성** — 아래 6개 섹션을 순서대로 채운다.
3. **저장** — 결과를 `[주제]-강의안.md` 파일로 저장하고 경로를 사용자에게 알려준다.

## 출력 구조

작성하는 강의안은 항상 다음 6개 섹션을 포함한다.

```markdown
# [주제] 강의안

> 대상: [대상 학습자] · 길이: [N분]

## 1. 학습 목표
- 이 강의가 끝나면 수강생이 할 수 있게 되는 것 3가지를 동사로 적는다.

## 2. 핵심 개념
- 주제를 이해하는 데 꼭 필요한 개념 3~5개를 한 줄 정의와 함께 적는다.
- 비개발자 기준으로 전문용어는 일상어로 풀어 쓴다.

## 3. 흐름 (강의 진행 순서)
- 도입 → 개념 설명 → 시연 → 실습 → 정리 순서로 시간 배분을 표로 제시한다.

## 4. 실습
- 수강생이 직접 손으로 해보는 단계별 실습 1개를 번호 목록으로 제시한다.
- 각 단계는 "무엇을 한다 → 무엇이 보이면 성공" 형태로 검증 기준을 포함한다.

## 5. 요약
- 오늘 배운 것을 3문장으로 정리한다.

## 6. 과제 / 다음 단계
- 수강생이 돌아가서 적용해 볼 작은 과제 1개를 제시한다.
```

## 작성 규칙

- 모든 문장은 `~이다`, `~한다` 설명체로 쓴다.
- 한 섹션이 비지 않도록 반드시 내용을 채운다.
- 실습 단계에는 항상 "성공 확인 기준"을 붙여, 수강생이 스스로 점검할 수 있게 한다.
- 예시는 한국 기업·공공 업무 맥락을 우선 사용한다.

## 예시 호출

- "RAG 기초로 강의안 만들어줘. 대상은 마케팅팀, 30분짜리로."
- "엑셀 자동화 수업 자료 작성해줘."
