# 경제뉴스 호재·악재 브리핑 (econ-news-brief)

경제뉴스 RSS를 수집 → CSV 정리 → 기업별 호재/악재 + 근거 판정 → Notion 보고서로
자동화하는 스킬이다. 매일 아침 브리핑(scheduled task)이나 단발 실행 모두 가능하다.

## 산출물

1. `articles_YYYYMMDD.csv` — 기사 단위 (소스·발행·제목·매칭기업·1차감성·점수·근거키워드·링크)
2. `companies_YYYYMMDD.csv` — 기업 단위 집계 (기업·워치리스트·언급수·호재·악재·중립·순점수)
3. `parsed_YYYYMMDD.json` — 정밀 판정용 원자료
4. Notion 페이지 — 기업별 호재/악재 표 + 헤드라인 + 거시 메모

## 워크플로 (이 순서대로)

### 1. RSS 수집 + 파싱
`scripts/econ_news_report.py`를 작업 폴더(outputs)에 복사한 뒤 실행한다:

```
python3 scripts/econ_news_report.py <outputs_dir>
```

스크립트는 아래 4개 경제지 RSS를 **샌드박스에서 직접**(urllib, SSL 검증 해제, User-Agent
지정) 받아 파싱한다. `web_fetch`는 한국경제·매경 등이 캐시/차단되므로 쓰지 말 것.

- 한국경제: `https://www.hankyung.com/feed/economy`
- 머니투데이: `https://rss.mt.co.kr/mt_news.xml`
- 연합인포맥스: `https://news.einfomax.co.kr/rss/allArticle.xml`
- 아시아경제: `https://www.asiae.co.kr/rss/economy.htm`

`<item>`의 title·link·description·pubDate를 파싱하고, 제목 45자 기준 중복 제거,
오늘(KST) 기사만 필터(없으면 전체 사용)한다. `--date YYYY-MM-DD`로 날짜 지정 가능.

> 피드를 바꾸려면 스크립트 상단 `FEEDS` 딕셔너리를 수정한다. 새 피드는 샌드박스에서
> urllib로 200 OK + `<item>` 파싱이 되는지 먼저 확인할 것 (mk·이데일리 등은 차단/SSL 이슈).

### 2. 기업 매칭 + 1차 감성
`assets/watchlist.txt`(또는 outputs의 watchlist.txt)의 관심 기업을 별칭 포함 우선 매칭하고,
기사에 등장하는 그 외 주요 기업도 자동 추출한다. 호재/악재 키워드로 1차 점수를 매긴다.
**watchlist.txt만 고치면 추적 대상이 바뀐다** (한 줄에 `대표명 | 별칭1, 별칭2`).

### 3. 정밀 호재/악재 판정 (가장 중요)
`parsed_YYYYMMDD.json`을 읽고, 키워드 1차 감성을 그대로 믿지 말고 **기사 내용을 근거로
직접 🟢호재 / 🔴악재 / ⚪중립을 판정**한다. 기업명이 본문에 스쳐 지나간 무관 기사(오탐)는
제외한다. 기업마다 한 줄 근거 + 출처 매체를 단다. 워치리스트 기업을 상단, 그 외 주목
기업을 아래에 배치한다.

### 4. Notion 페이지 생성
`notion-create-pages`로 보고서 페이지를 만든다. 부모 페이지는 사용자에게 처음 한 번
확인하고, 이후에는 같은 부모 아래에 날짜별로 누적한다 (기본 부모 예시 id:
`37cbdecf-087d-8116-b5bb-f65a81eea70c` "클로드 노트" — 사용자 워크스페이스에 맞게 교체).

- 제목: `📈 경제뉴스 호재·악재 브리핑 — YYYY-MM-DD`, 아이콘 📈
- 구성: ① 수집 현황(소스별 건수) ② 헤드라인 3줄 ③ 워치리스트 기업 호재/악재 표
  (기업·구분·핵심 근거·출처) ④ 워치리스트 외 주목 기업 표 ⑤ 거시·정책 메모
  (수출·고용·금리·환율 등) ⑥ 첨부 데이터 파일명
- 맨 아래 면책: 1차 감성은 키워드 스크리닝, 표는 정밀 판정, 투자 참고용·매매 권유 아님

### 5. 마무리
Notion 페이지 URL과 CSV 경로를 한두 문장으로 보고한다. 수집 실패 소스가 있으면 함께
알린다. 보고서는 한국어, 시사점 위주로 간결하게.

## 매일 자동 실행으로 만들기
사용자가 "매일 아침 자동으로"를 원하면 scheduled task(cron)로 등록한다. 권장:
`0 7 * * *`(매일 오전 7시). 스케줄 프롬프트에는 위 1~5단계와 4개 피드 URL, 워치리스트,
Notion 부모 페이지 id를 모두 적어 자체 완결형으로 만든다 (스케줄 런은 이 대화 기억 없음).

## 주의
- 호재/악재는 투자 판단의 참고 자료이며 매매 권유가 아니다. 면책 문구를 항상 포함한다.
- 키워드 1차 감성에는 오탐이 있다. 최종 표는 반드시 사람이 읽을 근거로 정밀 판정해 보정한다.
